# Basic-Calculator
A simple calculator built using HTML, CSS, and Vanilla JavaScript.
This project was created as a JavaScript practice project to understand DOM manipulation, event handling, functions, and managing calculator state.

Features
Addition +
Subtraction -
Multiplication *
Division /
Modulus %
Multiple operations in a single calculation
AC button to clear the calculator
DEL button to delete the last input
= button to calculate the result
Dynamic display using JavaScript

Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
